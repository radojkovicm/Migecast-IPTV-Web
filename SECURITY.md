# Security

Do not post credentials, provider URLs with authentication, session cookies or
private account data in public issues. If GitHub private vulnerability reporting
is enabled for this repository, use its Security tab for vulnerability reports.

Self-hosted deployments require HTTPS, closed account provisioning, owner MFA,
separate secrets, encrypted source credentials and a loopback-only media worker.
Deploy only after reviewing the templates for your environment.
The static demo has no accounts, backend, credentials or administrative endpoints.
